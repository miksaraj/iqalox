# `langspec/versions/0.1/`

Only the `0.1` **example programs** are kept in the tree (`examples/`). They are
here because tooling reads them: CI's `poc/` smoke test runs them against the frozen
Python interpreter, and the `poc/` release archive bundles them.

Everything else about `0.1` (its grammar, language reference and README) is preserved
by the `0.1.0` git tag, not by a copy in the tree — see
[`docs/EARLIER-VERSIONS.md`](../../../docs/EARLIER-VERSIONS.md).
